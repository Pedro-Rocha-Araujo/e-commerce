# Projeto E-Commerce 🛒 💸 💻

O presente projeto foi um objeto de estudo pessoal do Hook useContext do React. O projeto trata-se de uma interface de E-commerce.

<img width="1920" height="911" alt="thumbnail" src="https://github.com/user-attachments/assets/56134099-9ed0-4153-a3f5-f7abc66935ad" />

## 📱 Funcionalidades:
* Listagem de produtos
* Visualizar os detalhes do produto
* Adicionar produtos ao carrinho
* Gerenciar a quantidade de produtos adicionados

## 📝 Características:
* Fake API usando Json-server
* Abordagem Mobile-first
* useContext para compartilhamento global de dados

## 🔧 Ferramentas:
* Next.js
* React-toastify
* Axios
* Json-Server
